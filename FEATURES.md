# Feature Roadmap

## MVP: Safe desktop runner

- Start, pause, resume, and stop a session from a visible tray application.
- Run for a configured duration or indefinitely.
- Stop globally when `Ctrl+Alt+Q` is held for two seconds.
- Stop when the pointer is moved rapidly into the upper-left corner three times.
- Release held keys and mouse buttons during every shutdown path.
- Load and validate configuration for approved websites, folders, file types, applications, and timing ranges.
- Produce human-like curved pointer movement, variable scrolling, and synthetic typing.
- Log only actions generated by the runner.

## Browser activity

- Launch a dedicated browser profile without saved personal credentials or payment information.
- Search using generated queries from configured family-safe topic categories.
- Restrict navigation to approved domains.
- Search YouTube, select results, play and pause videos, seek, adjust volume, and scroll.
- Open, switch, reorder, and close tabs.
- Minimize, maximize, restore, resize, and close browser windows.
- Block downloads, uploads, purchases, messages, posts, comments, forms, account settings, and login flows.
- Abandon CAPTCHAs, permission prompts, advertisements, pop-ups, and unknown dialogs safely.

## Desktop and file activity

- Open and close File Explorer.
- Navigate only within configured folder roots.
- Change safe views, select files, scroll, and move backward or forward through folder history.
- Open configured file types in approved read-only viewers.
- Close viewers and return to File Explorer.
- Block deletion, renaming, moving, copying, editing, sharing, printing, and uploading.

## Procedural behavior

- Build multi-step activity chains instead of replaying recorded sequences.
- Choose activities with configurable weighted randomness.
- Apply penalties to recently used actions, queries, videos, sites, and folders.
- Vary behavior by elapsed session time and time of day.
- Insert short pauses, long idle periods, hesitation, pointer overshoot, and synthetic typo correction.
- Support random production runs and seeded reproducible diagnostic runs.

## Reliability and observability

- Detect loss of focus, stalled pages, browser crashes, invalid paths, and unknown windows.
- Retry transient failures once, then choose another safe activity.
- Restore a known-safe browser or File Explorer state after recoverable failures.
- Stop safely after severe or repeated failures.
- Write structured session, action, recovery, and shutdown logs.
- Provide current status and the most recent safe action through the tray interface.

## Testing milestones

- Unit tests for allowlists, action validation, weighted selection, history penalties, and configuration.
- Adapter tests for browser, File Explorer, input generation, hotkeys, and shutdown cleanup.
- Simulation covering thousands of proposed actions without controlling the live desktop.
- Failure-injection tests for crashes, unexpected dialogs, unavailable sites, and disconnected networks.
- Accelerated endurance test representing at least 12 hours.
- Supervised live-PC soak test before unattended use.

## Explicitly out of scope

- Capturing or storing physical keyboard input.
- Concealing the runner, bypassing monitoring, or resisting shutdown.
- CAPTCHA or anti-bot bypass.
- Account login or access to a normal personal browser profile.
- Communication, commerce, file mutation, software installation, or unrestricted browsing.
- Autonomous screen clicking outside recognized, validated targets.
